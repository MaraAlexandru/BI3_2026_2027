Web Technologies | Lab 5 | 60 minutes

Student Working Guide

Build a four-page Bootstrap furniture store from the supplied plain HTML starter.

Before starting

Copy the entire starter folder and rename your copy my-store. Work in that copy. Keep all four pages together so their relative links continue to work. Open my-store/index.html in a browser and the same folder in your editor.

The starter pages contain furniture content and semantic HTML. They contain no Bootstrap classes, stylesheet or script. Comments beginning with TODO mark elements that you must create. Keep existing IDs because this guide uses them to identify exact editing locations.

The final folder is the reference solution. Use it after attempting a step or when comparing completed pages. Do not copy the solution over your working folder.

The lab lasts 60 minutes. Use HTML, Bootstrap classes and the official Bootstrap bundle. Internet access is required for the CDN files. The cart has fixed sample values. The form uses browser validation and has no backend.

Step 1. Load Bootstrap on every page, 0 to 5 minutes

Open each of the four HTML files. In <head>, find the stylesheet TODO comment after <title>. Replace that comment with this link. Keep the existing UTF-8 and viewport declarations.

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

In the same file, find the bundle TODO comment just before </body>. Replace it with this script. Repeat both changes in all four files.

<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>

The stylesheet supplies Bootstrap presentation. The bundle supplies behavior for the navbar, alert, accordion and modal. Loading the bundle is enough for the data-attribute examples used here. You do not need to write a JavaScript handler.

Checkpoint. Reload every page. The default font changes. Each page contains one Bootstrap CSS link and one matching bundle.

The selector #mainNavigation in the button must match the collapse region ID. The button starts with aria-expanded="false" because the narrow-screen menu starts closed. Bootstrap updates that state when the menu changes.

Apply the same layout classes, theme attribute and toggle button in products.html, cart.html and contact.html. Mark Products active on Products, Cart active on Cart and Contact active on Contact. Do not mark Home active on every page.

Checkpoint. Navigate between all four files. On a narrow screen the toggle opens and closes the menu. On a wide screen the links stay visible. Exactly one link is active per page.

Step 8. Build an accordion on Home, 48 to 54 minutes

Return to index.html. Find the accordion TODO inside #faqSection. Create the wrapper and two items below. Keep this markup outside the hero.

<div class="accordion" id="storeFaq">
    <div class="accordion-item">
        <h3 class="accordion-header">
            <button class="accordion-button" type="button" data-bs-toggle="collapse"
                    data-bs-target="#careAnswer" aria-expanded="true"
                    aria-controls="careAnswer">How do I care for oak?</button>
        </h3>
        <div id="careAnswer" class="accordion-collapse collapse show" data-bs-parent="#storeFaq">
            <div class="accordion-body">Use a soft cloth and wipe spills promptly.</div>
        </div>
    </div>
    <div class="accordion-item">
        <h3 class="accordion-header">
            <button class="accordion-button collapsed" type="button" data-bs-toggle="collapse"
                    data-bs-target="#assemblyAnswer" aria-expanded="false"
                    aria-controls="assemblyAnswer">Is assembly required?</button>
        </h3>
        <div id="assemblyAnswer" class="accordion-collapse collapse" data-bs-parent="#storeFaq">
            <div class="accordion-body">Tables need light assembly. Chairs arrive ready to use.</div>
        </div>
    </div>
</div>

In the first item, the button target and panel ID both refer to careAnswer. The second uses assemblyAnswer. The first starts open because its panel has show and its button starts expanded. The second starts closed, so its button has collapsed. Both panels refer to #storeFaq through data-bs-parent, which keeps only one item open at a time.

Checkpoint. Open assembly. Care closes. Open care again and confirm the reverse. If nothing happens, check the bundle and matching targets.

Step 9. Build a delivery modal on Products, 54 to 58 minutes

Open products.html. Replace the delivery-trigger TODO in #collectionHeader with this new button.

<button class="btn btn-outline-success" type="button" data-bs-toggle="modal"
        data-bs-target="#deliveryModal">Delivery information</button>

Replace the modal TODO after the product grid with the following markup. Keep it outside #productGrid, otherwise the grid treats it as a product column.

<div class="modal fade" id="deliveryModal" tabindex="-1"
     aria-labelledby="deliveryTitle" aria-hidden="true">
    <div class="modal-dialog modal-dialog-centered">
        <div class="modal-content">
            <div class="modal-header">
                <h2 class="modal-title fs-5" id="deliveryTitle">Furniture delivery</h2>
                <button class="btn-close" type="button" data-bs-dismiss="modal" aria-label="Close"></button>
            </div>
            <div class="modal-body">Delivery is arranged by item size and destination. Contact us for a quote.</div>
            <div class="modal-footer">
                <button class="btn btn-secondary" type="button" data-bs-dismiss="modal">Close</button>
            </div>
        </div>
    </div>
</div>

The trigger points to #deliveryModal. The dialog title is associated through aria-labelledby="deliveryTitle". Both close buttons use data-bs-dismiss="modal". Bootstrap supplies the overlay and focus behavior.

Checkpoint. Open the modal and close it with its button. Open it again and press Escape. The rest of the page becomes usable after closing.

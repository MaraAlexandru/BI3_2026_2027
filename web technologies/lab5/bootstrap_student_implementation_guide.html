Bootstrap Furniture Store

Explore Bootstrap's responsive layout and main interface components in a static furniture store.

Learning outcomes

Use Bootstrap 5.3.3 classes to build responsive page structure, product cards, navigation, forms, tables and feedback components. Test the interactive components powered by the Bootstrap bundle.

Use semantic HTML and Bootstrap classes. Do not add PHP, a database, a custom stylesheet or custom JavaScript. The enquiry form is a front-end example and does not store data.

Work during the lab

Open the project in a browser and editor. Locate the CDN stylesheet and JavaScript bundle. Resize the page and inspect how the navbar, container and product grid respond.

Adjust the product collection so it has at least four cards. Keep card spacing consistent and make the main and secondary actions visually distinct. Change one responsive breakpoint and add one labelled form field.

Open and close the dropdown, dismissible alert, collapse panel, accordion, modal and cart offcanvas. Check the form's browser validation and the table at a narrow width.

Completion criteria

  • The page uses Bootstrap 5.3.3 from the CDN.
  • Navigation, grid and cards adapt to viewport width.
  • Bootstrap interactive components open, close or dismiss as expected.
  • Form labels are connected to their controls and native constraints work.
  • The table remains usable on a narrow screen.
  • The project remains plain HTML with Bootstrap classes and its official bundle.

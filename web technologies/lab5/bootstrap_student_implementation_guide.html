Bootstrap Furniture Store

Turn four plain HTML pages into a responsive store interface.

Start here

Copy the starter folder and rename your copy my-store. Open its four pages in your editor. Follow the detailed working guide in order.

Open the step-by-step working guide

Inspect the plain HTML starting point or view the reference solution.

Work to complete

Load Bootstrap on every page. Apply layout, grid, spacing and component classes to the supplied HTML. Create the navigation toggle, badges, fourth product card, dismissible alert, extra form controls, accordion and delivery modal.

Use HTML and Bootstrap 5.3.3 with its official bundle. Keep all four pages together. The cart has fixed sample values and the form does not store data.

Submission

Submit the completed my-store folder with Home, Products, Cart and Contact. Check navigation, responsive layout and interactive components on every relevant page.
